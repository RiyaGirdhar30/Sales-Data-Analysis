# 📊 Sales Data Analysis

A beginner-friendly Python data analysis project that analyzes sales data using Pandas, NumPy, and Matplotlib.

## 📌 Project Overview

This project analyzes a sample sales dataset to understand sales performance across different products, categories, regions, and months.

The project calculates important sales metrics and creates visualizations to make the results easier to understand.

## 🚀 Features

- Load sales data from a CSV file
- Inspect and understand the dataset
- Convert dates into datetime format
- Calculate sales for each order
- Calculate total sales
- Calculate average order value
- Analyze sales by product
- Find the top-selling product
- Analyze sales by category
- Find the top-selling category
- Analyze sales by region
- Find the top-selling region
- Analyze monthly sales
- Find the best sales month
- Calculate sales standard deviation using NumPy
- Create sales visualizations using Matplotlib
- Save charts automatically

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone git clone https://github.com/RiyaGirdhar30/Sales-Data-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Sales_Data_Analysis
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the analysis

```bash
python sales_analysis.py
```

The program will display the analysis results and generate charts inside the `charts` folder.

## 📁 Dataset

The dataset is stored in:

```text
data/sales_data.csv
```

It contains information such as:

- Order Date
- Product
- Category
- Region
- Quantity
- Price

Sales for each order are calculated using:

```text
Sales = Quantity × Price
```
